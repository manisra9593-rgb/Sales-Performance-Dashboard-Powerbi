# Sales Performance Dashboard - Power BI

## 📌 Project Overview
This project is an interactive Sales Performance Dashboard developed using Power BI Desktop. It provides insights into sales performance by analyzing total sales, total cost, profit margin, products, categories, and regions.

## 📊 Dashboard Features
- KPI Cards
  - Total Sales
  - Total Cost
  - Profit Margin
  - Total Orders
- Monthly Sales Trend
- Sales by Product
- Sales by Category
- Sales by Region
- Interactive Slicers (Year, Category, Region)
- Custom Report Page Tooltip
- Region Details Report Page

## 🛠️ Tools & Technologies
- Power BI Desktop
- Power Query
- DAX (Data Analysis Expressions)

## 📈 Key DAX Measures
- Total Sales
- Total Cost
- Total Profit
- Profit Margin %
- Total Orders
